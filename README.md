# cafe_practice

カフェサイトのポートフォリオ作品です。初めての制作になります。

「Kissa Sakura」というコンセプトに合わせ、桜のようなやさしい色味と柔らかいフォントを採用し、落ち着いた雰囲気のカフェサイトを制作しました。

---

## 使用技術
- HTML
- CSS
- JavaScript

---

## 工夫した点
- 配色とフォントを統一し、柔らかい世界観を表現
- ハンバーガーメニューを実装し、スマホでも操作しやすいUIに改善
